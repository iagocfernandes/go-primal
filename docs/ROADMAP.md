# GO PRIMAL — Replanned Production Route

## North-star experiment
Can an event inside GO PRIMAL cause a player to perform a meaningful real-world action they otherwise would not have done?

## P0 — Foundation
- Supabase project + migrations.
- Auth.
- Profile / Gorilla / Village bootstrap.
- Immutable resource ledger.
- Server-authoritative building upgrade.
- Staging deployment.

## P0.5 — Proof Engine
- Canonical activities.
- Evidence model.
- Verification states.
- Dedupe.
- Admin review queue.
- Reward policy versioning.

## P1 — Strava + Real Life Loop
- Connect Strava.
- Webhook subscription.
- Activity worker.
- Activity feed.
- Activity -> reward -> upgrade.
- Clear provenance badge.
- Manual proof fallback.

## P2 — Real Multiplayer
- Two real villages.
- Visit village.
- Alliance request + explicit acceptance.
- Solo raid server resolver.
- Retaliation notification.
- Anti-bullying and shields.

## P3 — Closed Alpha
- 5–10 real users first.
- Admin console.
- Economy tuning without deploy.
- Analytics and session/event logs.
- Fraud review.
- Measure incremental real-world action.

## P4 — Social depth
- Warbands.
- Kingdom contribution.
- Kingdom War.
- Special missions.
- Social activity feed.

## P5 — Native proof bridge
- iOS companion: HealthKit workouts + steps, later focus shielding.
- Android companion: Health Connect.
- Same backend and Proof Engine.

## Explicitly deferred
- World map.
- Marketplace.
- Deep equipment stats.
- Complex classes.

- Full native app.
